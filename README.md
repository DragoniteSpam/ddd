# DDD

Haha, geddit? It's three "D"s.

DDD is an assortment of general-purpose functions that some of us use pretty often in 3D in GameMaker.

## What it is

 - Assorted vector functions (of the array-of-numbers variety)
 - Assorted qaternion functions (also of the array-of-numbers variety)
 - Assorted matrix functions (to supplement and/or fix the GM matrix functions)
 - Assorted frustum functions
 - screen to world and world to screen
 - There's a demo scene that shows off some of the functions in it

## What it isn't

 - 3D model loading
 - 3D animations
 - Fancy 3D rendering shader effects
 - A 3D level editor
 - A 3D collision system
 - A 3D physics system
 - ✨🤖 Vibecoded ✨🧪🚀

This project was slightly more exciting before [this happened](https://releases.gamemaker.io/release-notes/2026/GMRT_MS_20) but ~~we~~ I procrastinated hard and if we're being real, GMRT isn't going to be out of beta for quite a lot of years.
